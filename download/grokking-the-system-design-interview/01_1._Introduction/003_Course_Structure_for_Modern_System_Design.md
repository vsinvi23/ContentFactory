# Course Structure for Modern System Design

Explore this course in detail, designed into four sections, starting with core concepts and non-functional requirements, then covering the core building blocks of distributed systems, and culminating in sixteen end-to-end design problems to prepare you for system design interviews at larger companies.

We'll cover the following...

## Structure of the course[#](https://www.educative.io/courses/grokking-the-system-design-interview/course-structure-for-modern-system-design#Structure-of-the-course)

This course consists of more than 40 chapters organized into five sections:

1. **Introduction:** This section spans five chapters. It defines System Design and its importance to developers, then introduces the [System Design interview](https://www.educative.io/courses/grokking-the-system-design-interview/getting-ready-for-the-system-design-interview), how AI has reshaped it, and the role of [mock interviews](https://www.educative.io/mock-interview). Later chapters cover preliminary concepts, essential [non-functional requirements](https://www.educative.io/courses/grokking-the-system-design-interview/availability), and [back-of-the-envelope calculations](https://www.educative.io/courses/grokking-the-system-design-interview/put-back-of-the-envelope-numbers-in-perspective) for resource estimation.
2. **Building blocks:** We explore sixteen essential distributed-systems [building blocks](https://www.educative.io/courses/grokking-the-system-design-interview/introduction-to-building-blocks-for-modern-system-design), each in a dedicated chapter, followed by seven AI building blocks: models as components, ranking pipelines, tokens and context windows, embeddings and retrieval, RAG and agents, model serving, and evaluation. The section then transitions into [design problems](https://www.educative.io/courses/grokking-the-system-design-interview/wrapping-up-the-building-blocks-discussion) through the RESHADED approach.
3. **Design problems:** This core section analyzes eighteen design problems. Several add an AI feature built from the AI building blocks, such as conversational video discovery in YouTube, ranked timelines in Twitter and the newsfeed, AI-assisted scheduling in Google Calendar, and incident analysis in metrics monitoring.
4. **System Design for the AI era:** AI runs through the course, from the interview chapter to the AI building blocks and the AI features in classic designs. This section completes it with four AI-native design problems: ChatGPT, a data infrastructure system for AI/ML, an LLM-powered customer support bot, and an AI-powered code assistant.
5. **Epilogue:** This final section contains three parts. First, [spectacular failures](https://www.educative.io/courses/grokking-the-system-design-interview/lessons-from-system-failures) demonstrate how small errors can crash large systems and how to mitigate them. Second, [concluding remarks](https://www.educative.io/courses/grokking-the-system-design-interview/conclusions) summarize key learnings. Finally, supplementary chapters provide resources to strengthen your System Design concepts.

> **Note:** While each of these chapters is independent, we recommend reading them in the presented sequence for smooth learning.

## Strengths of the course[#](https://www.educative.io/courses/grokking-the-system-design-interview/course-structure-for-modern-system-design#Strengths-of-the-course)

This course focuses on areas that are often underexplored in other System Design resources. The table below summarizes how it differs.

|  |  |
| --- | --- |
| **Strengths** | **Advantage** |
| Building blocks | This is a modern approach to system design where we construct bigger artifacts using smaller building blocks. |
| Building blocks as design problems | We’ll treat each one of our building blocks as a stand-alone, mini design problem. |
| Incremental improvement to design | Layer-by-layer design solution addresses added bottlenecks, designing simple and incremental solutions to complex systems. |
| Evaluating the design | Accountability of the provided design solution shows the performance of our design. |
| Solving the traditional problems with updated designs | This course is up to date with the latest industry demands. |
| New design problems added | This course contains updates to decades-old system design courses. |
| Careful collection of design problems | Each problem has its unique aspects in terms of problem-solving and designing. |
| Contributions by experts from FAANG | Learn from the best. |
| AI-based quizzes and assessments | These assessments and interviews evaluate learner’s concepts of system design. |
