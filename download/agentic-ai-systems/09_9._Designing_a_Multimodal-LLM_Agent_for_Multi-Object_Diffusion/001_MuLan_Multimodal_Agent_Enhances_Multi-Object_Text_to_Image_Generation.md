# Introduction to MuLan and the Multi-Object Generation Challenge

Understand MuLan's agentic design that improves text-to-image generation by dividing complex prompts into manageable single-object tasks. Learn how its architecture uses LLM planning, progressive diffusion, and VLM feedback for enhanced control, self-correction, and accuracy in creating detailed images.

> **The problem space:** Text-to-image generation

## The one-shot process vs. an agentic architecture[#](https://www.educative.io/courses/agentic-ai-systems/introduction-to-mulan-and-the-multi-object-generation-challenge#The-one-shot-process-vs-an-agentic-architecture)

In recent years, we’ve seen an explosion in the capabilities of text-to-image (T2I) models. These AI systems can take a simple text prompt and produce visually appealing, high-quality images in a single step. As the underlying models have improved, their ability to handle compositional requests has improved remarkably.

However, as agentic system designers, our goal is to think beyond the capabilities of a single model call and consider the architecture of the entire system. The inherent architectural limitation of a “one-shot” generative process is its lack of fine-grained control, interactivity, and a mechanism for self-correction. When a one-shot model fails to capture all the constraints in a complex prompt, our only option is to try again.

Examples of T2I models struggling with compositional prompts. Notice the incorrect attribute bindings (e.g., a yellow chair instead of a green one) and incorrect spatial positions in the outputs from standard models like SD-v1.4 and SDXL, compared to the correct image generated by MuLan

As the image above illustrates, even powerful diffusion models can sometimes struggle with prompts that require precise compositional understanding, leading to issues mentioned below.

- **Incorrect spatial positions:** The model might place an object on the left when it was requested on the right.
- **Flawed attribute bindings:** It might generate a yellow chair and a green table, mixing up the colors and objects.

These potential failures highlight the need for a more robust and reliable process. This is where an agentic system design offers a different architectural approach. The core question for us as designers is not just “Can the model do it?” but also:

- How can we make the generation process more reliable and less opaque?
- How can we give the user (or the system itself) more control over the process?
- How can the system correct its own mistakes as it goes?

It is these system-level advantages, control, interactivity, and reliability, that motivate the need for an agentic system design for complex generative tasks.

## MuLan: A “divide and conquer” approach to image generation[#](https://www.educative.io/courses/agentic-ai-systems/introduction-to-mulan-and-the-multi-object-generation-challenge#MuLan-A-divide-and-conquer-approach-to-image-generation)

To solve the challenges of control and reliability in complex image generation, we can transform the process from a single action into a multi-step project managed by an agent. This is the core idea behind **MuLan**, a training-free system that uses a multimodal-LLM to generate complex images by mimicking the workflow of a human painter.

A human painter doesn’t create a complex scene all at once. They start with a high-level plan, add objects to the canvas one by one, and correct mistakes as they go. MuLan is designed to do the same.

Instead of trying to solve the entire complex prompt in a single step, MuLan uses a “divide and conquer” strategy. It breaks one difficult text-to-image task into a sequence of much easier, single-object generation sub-tasks. This sequential, step-by-step process is the key to its improved reliability and control.

## High-level architecture of MuLan[#](https://www.educative.io/courses/agentic-ai-systems/introduction-to-mulan-and-the-multi-object-generation-challenge#High-level-architecture-of-MuLan)

MuLan’s architecture is built on three core modules that work together in a continuous loop:

![Architecture of a multimodal-LLM agent for progressive and interactive multi-object diffusion](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "Architecture of a multimodal-LLM agent for progressive and interactive multi-object diffusion")

Architecture of a multimodal-LLM agent for progressive and interactive multi-object diffusion

1. **LLM planning:** At the very beginning, an LLM acts as a planner. It decomposes the user’s original, complex prompt into an ordered sequence of simpler sub-prompts, each focused on generating just a single object. In practice, the planner also assigns each object a rough bounding region and a generation order (the default is left-to-right and bottom-to-top). This acts as a lightweight layout plan, guiding the diffusion model to place objects in the correct general positions and preserve spatial relations.
2. **Progressive, single-object diffusion:** A standard, pre-trained diffusion model is then used as a tool to generate the objects one at a time. It paints the first object on a blank canvas, then paints the second object on the image containing the first, and so on, progressively building the scene. To ensure the object is placed correctly within its planned mask, the system uses a technique called backward cross-attention guidance.
3. **VLM-feedback control:** This is the self-correction mechanism. After each object is generated, a Vision Language Model (VLM) acts as an internal “critic.” It inspects the image to see if the newly added object violates any of the constraints from the original prompt. If it detects a mistake, it provides feedback to the diffusion model to re-generate the object before moving to the next stage. This is done by adjusting the backward guidance and hyperparameters for that stage. This mechanism is a powerful self-correction loop. While the overall MuLan system follows a high-level plan-and-execute strategy (planning all objects, then generating them), this self-correction loop acts as a quality control check within each ‘execute’ step, allowing the agent to iteratively fix its own mistakes.

This layered design, combining planning, sequential action, and a feedback loop, allows MuLan to handle complex compositional prompts with much greater accuracy and control than a traditional, one-shot T2I model.
