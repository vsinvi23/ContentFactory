## Machine Learning Model Diagnosis

This exam has been designed to test the machine learning model
concepts (diagnosis and data preparation) that you have learned so far.

The exam consists of 9 Multiple Choice Questions (MCQs): You are given possible answers and are asked to select one (and only one) correct answer from the given answers.

The following concepts/skills of Machine Learning will be assessed in this exam:

- Classification
- Feature important
- Confusion matrix
- Random forest
- Statistics
- Random forest tuning
- Decision tree tuning
- Model deploy
- Deep learning
